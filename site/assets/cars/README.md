# 차량 사진 넣는 곳

홈 화면 "내 차 선택하기" 카드에 쓰이는 사진입니다.
**차량 한 대당 폴더 하나**이고, 그 폴더에 사진을 **`photo.jpg`** 라는 이름으로 넣으면 됩니다.

```
site/assets/cars/
├─ 포터II_냉동탑차/
│    photo.jpg        ← 여기 넣기
├─ 포터II_윙바디/
│    photo.jpg
└─ …  39개 폴더
```

사진이 없는 폴더의 차는 회색 트럭 그림이 대신 나옵니다.
**한 장씩 넣는 대로 그 차부터 바뀌니** 전부 준비될 때까지 기다릴 필요 없습니다.

## 같은 사진을 여러 차에 쓰는 경우

겉모습이 같은 차들(스타리아 / 스타리아 Hybrid, 카고 2WD / 4WD 등)은
**같은 사진 파일을 각 폴더에 하나씩 넣으면 됩니다.** 파일이 중복돼도 상관없습니다.

## 사진 규격

- **가로:세로 4:3** (예 800×600). 다른 비율이어도 잘리지 않고 안에 맞춰 들어갑니다.
- **배경은 흰색이나 밝은 회색**이 카드와 가장 잘 어울립니다.
- 파일 하나당 **200KB 이하**를 권합니다. 카드가 한 화면에 여러 장 뜨기 때문입니다.
- 확장자는 반드시 **`.jpg`**, 이름은 반드시 **`photo.jpg`** 입니다.

## 차량이 새로 늘어나면

엑셀에 차량을 추가하고 `데이터갱신.bat` 을 돌리면 카드가 자동으로 늘어납니다.
폴더 이름은 **카드에 보이는 차량명에서 띄어쓰기를 `_` 로 바꾼 것**이라,
같은 규칙으로 폴더를 만들어 주시면 됩니다. (괄호는 `_` 로 바뀌고 닫는 괄호는 없어집니다)

## 사진 구할 때 주의

제조사 홈페이지 이미지를 그대로 가져다 쓰면 저작권 문제가 생길 수 있습니다.
아래 중 하나로 확보하시는 편이 안전합니다.

- 현대·기아 **딜러/대리점에 요청**해 받은 판촉용 이미지
- 제조사 **미디어센터/보도자료**의 배포용 사진 — 이용 조건을 확인하고 사용
- **직접 촬영**한 실차 사진 (출고 차량, 전시장 등)

특장차는 제작 업체마다 모양이 달라, 실제로 출고하신 차량 사진이
정확하고 신뢰도도 높습니다.
