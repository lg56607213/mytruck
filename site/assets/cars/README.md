## 사진 규격

- **가로:세로 4:3** (예 800×600). 다른 비율이어도 잘리지 않고 안에 맞춰 들어갑니다.
- **배경은 흰색이나 밝은 회색**이 카드와 가장 잘 어울립니다.
- 파일 하나당 **200KB 이하**를 권합니다. 카드가 한 화면에 여러 장 뜨기 때문입니다.
- 확장자는 `.jpg` 로 맞춰 주세요.

## 세부사양별로 다른 사진을 쓰고 싶다면

예를 들어 포터II 냉동탑차만 따로 찍은 사진이 있다면,
`assets/catalog.js` 의 `IMG_BY_BODY` 에 한 줄만 추가하면 됩니다.

```js
const IMG_BY_BODY = {
  "포터II|냉동탑차": "porter2-freezer",   // → porter2-freezer.jpg
};
```

## 사진 구할 때 주의

제조사 홈페이지 이미지를 그대로 가져다 쓰면 저작권 문제가 생길 수 있습니다.
아래 중 하나로 확보하시는 편이 안전합니다.

- 현대·기아 **딜러/대리점에 요청**해 받은 판촉용 이미지 (가장 확실합니다)
- 제조사 **미디어센터/보도자료**의 배포용 사진 — 이용 조건을 확인하고 사용
- **직접 촬영**한 실차 사진 (출고 차량, 전시장 등)

실차 사진이 오히려 신뢰도가 높아 클릭률에 유리한 경우가 많습니다.
